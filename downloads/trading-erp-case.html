BEFORE — 導入前

八個一直無法解決的營運痛點

紙本 + Excel 時代
  • 業務在外接單，回辦公室才 key Excel，常常忘了報哪個客戶
  • 新客戶名片手動 key 統編、電話、地址，10 張花 1 小時
  • 產品價格表各業務手上版本不同，報錯價自己吸收
  • 電子發票外包記帳事務所開立，每筆都要傳檔案來回
  • 會計傳票銷貨/進貨單會計重新 key 一次到記帳軟體
  • 應收應付月結會計手動算到天昏地暗，常算錯
  • 庫存盤點每季手動清點，紙本 vs 系統永遠對不起來
  • 業績獎金毛利每月手算（毛利-營業稅-員工稅率），3 天才結算完
AFTER — 數位化後
  • LIFF 報價單業務在外手機開單，客戶/產品 autocomplete
  • 名片 OCR拍照 → Google Vision 自動抽公司/聯絡人/電話/統編/Email
  • 產品主檔統一，所有業務看同一版價格，改一次全公司同步
  • 電子發票自開，Turnkey API 整合，B2C 載具/捐贈/B2B 統編全自動
  • 自動傳票 hooks銷貨/進貨自動產生分錄（Dr/Cr 自動帶入）
  • 應收應付自動結算，到期前 15 天提醒，月結 PDF 一鍵下載
  • 庫存進銷存連動，銷貨自動扣庫存、進貨自動補
  • 業績獎金自動計算每月 1 號自動結算（毛利-稅-員工稅率）

🎯 系統的核心價值：把人腦記變成系統記

不是新增工具，是把分散的 Excel、紙本、人腦記憶整合到一個系統。業務在外用 LINE 就能下單，會計不用重複 key 帳，老闆隨時看儀表板就知道公司狀況。

8 種常見客戶問題自動處理

📋 查報價

「上次報多少」→ AI 查最新 quotation 回 PDF 連結。

📦 查進度

「我訂的什麼時候到」→ 查 sales-order 狀態。

📄 查發票

🆕 新詢價

「這個產品有貨嗎」→ 查產品 + 庫存 + 通知業務。

資料安全

多租戶 SaaS 級資安標準

客戶資料、產品價格、客戶名單都是商業機密。FDE 採用銀行業同等級的安全規範，多租戶 SaaS 確保不同公司資料完全隔離。

🔒 密碼安全 bcryptjs cost=10

所有員工密碼經 bcrypt 雜湊（單向加密）後儲存。即使 DB 被偷，駭客也無法還原原始密碼。

🎫 雙重認證 JWT Bearer + HTTP-only Cookie

LIFF 用 JWT Bearer（id-token 驗證），Web 後台用 HTTP-only cookie（12 小時 TTL）。XSS 攻擊偷不到 token。

🛡️ HTTP 安全頭 Helmet + CSP

Content Security Policy 防止 XSS 注入、防止點擊劫持、強制 HTTPS。OWASP Top 10 全過。

🏢 多租戶完全隔離 tenantId + assertTenantIsolation

每個業務表都有 tenantId 欄位。Service 層 query 強制注入 tenantId 過濾；fetch 後二次驗證 row 屬於正確 tenant，防範跨租戶資料洩漏 bug。

📋 完整稽核日誌 AuditLog 表

每一個 API 呼叫都記錄：誰、何時、做什麼、改了哪些欄位、IP 來源、UserAgent。後台「操作紀錄」頁可查詢任何爭議。

📑 電子發票安全 S3 per-tenant prefix

電子發票 XML 儲存在 S3 bucket 的 per-tenant prefix 子目錄。Turnkey 服務只能讀指定 prefix，不會跨租戶取錯發票。
